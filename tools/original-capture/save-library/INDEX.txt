Original-game save library (Star Wars Rebellion, GOG build, this VM)
To use one: copy it over a slot, e.g.
  copy /y C:\Rebellion\SaveLibrary\NAME.sav C:\Rebellion\SaveGame\SAVEGAME.007
then F1, Saved Games. Saved Games lists filled slots plus one empty row,
so fill slots without gaps. Slot 5 holds empire-day488-late: leave it.
Mac side: tools/original-capture/vm-game.sh save-in FILE SLOT does the same.
