Generated HD assets are local and are not distributed with the engine.

Use `scripts/faithful_hd_pipeline.py` and the
[faithful-HD plan](../../docs/plans/2026-09-10-faithful-hd-pipeline/). The game
defaults to original-parity assets. Optional HD files require verified
provenance and explicit approval in `manifest.json` before the runtime can use
them. Legacy UltraSharp and PBRify outputs remain comparison candidates only.
