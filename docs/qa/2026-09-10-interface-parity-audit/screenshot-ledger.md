# Original Interface Screenshot Ledger

This ledger classifies 370 retained reference images. The
[SHA-256 manifest](reference-captures/SHA256SUMS) fixes their current contents;
the [reference ledger](reference-ledger.json) records provenance, locale, and
authority. These images establish the discovery baseline. Final acceptance uses
lossless captures from an owned, unmodified English installation plus executable
or decompilation evidence for geometry and commands.
