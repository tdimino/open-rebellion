# P58A tactical resource-join artifacts

This directory preserves deterministic browser evidence for the exact
game-data-to-tactical-resource join and complete tactical runtime pack.

| File | Purpose |
|---|---|
| `full-summary.json` | Complete 28-case tactical regression result. |
| `alliance-640x480-result.json` | Alliance requests, resource joins, pack counts, and diagnostics. |
| `empire-640x480-result.json` | Imperial requests, resource joins, pack counts, and diagnostics. |
| `alliance-640x480.png` | Native-size Alliance browser capture. |
| `empire-640x480.png` | Native-size Imperial browser capture. |
| `alliance-1280x800.png` | Letterboxed Alliance browser capture. |
| `empire-1280x800.png` | Letterboxed Imperial browser capture. |
| `astra-browser-acceptance.json` | Astra medium browser-evidence verdict and limits. |

These are A1 reconstruction artifacts, not lossless A0 original-executable
baselines. They prove resource identity and transport, not production rendering
of every mapped family. No strict tactical cell is accepted by this bundle.
