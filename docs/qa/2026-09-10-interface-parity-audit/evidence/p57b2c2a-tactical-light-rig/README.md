# P57B2C2A tactical light-rig artifacts

This directory preserves the deterministic browser evidence for the
source-traced Direct3D retained-mode light rig.

| File | Purpose |
|---|---|
| `focused-summary.json` | Four-case camera-journey gate across both factions and viewports. |
| `full-summary.json` | Complete 28-case tactical regression result. |
| `alliance-640x480-result.json` | Alliance requests, hashes, diagnostics, and exact light probe. |
| `empire-640x480-result.json` | Imperial requests, hashes, diagnostics, and exact light probe. |
| `alliance-640x480.png` | Native-size Alliance browser capture. |
| `empire-640x480.png` | Native-size Imperial browser capture. |
| `alliance-1280x800.png` | Letterboxed Alliance browser capture. |
| `empire-1280x800.png` | Letterboxed Imperial browser capture. |
| `astra-browser-acceptance.json` | Astra medium visual review and acceptance limits. |

These are A1 reconstruction artifacts, not lossless A0 original-executable
baselines. No strict tactical cell is accepted by this bundle.
